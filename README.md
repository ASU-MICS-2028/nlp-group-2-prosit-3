# Ayamra Dictation: Speech-to-Text for African Hospitals (ICS554 Prosit 3)

A study and prototype for Ayamra, a hospital network that wants doctors to dictate notes and get transcripts.
We ask whether RNNs (the consultant's advice) are the right tool for AfriSpeech-200, and what we would recommend instead.
